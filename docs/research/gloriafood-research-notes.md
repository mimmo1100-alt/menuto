# GloriaFood research notes (for Menuto spec)
Sources: the live GloriaFood ordering page of a partner restaurant, the admin report in gloriafood-admin-report.md (made by Claude in Chrome inside the owner's partner account), 11 GloriaFood YouTube tutorials, gloriafood.com pages, the Play Store page of their order-taking app, and their public API docs (github.com/GlobalFood/integration_docs).
- Shutdown: GloriaFood closes 30 Apr 2027 (banner in admin); Oracle points users to FoodAmigos.
- Order app: iOS+Android; loud alert; 4 min to accept else "missed" (customer email + retry); accept -> prep minutes; reject/cancel with reason (customer popup+email, can edit & retry); orders outside hours queue silently until opening; tabs All/In progress/Ready; swipe -> ready; menu: test order, clear orders, pause services (per service, rest of day or N hours, message); mark items/addons out of stock from app; auto-accept w/ default prep (pickup 20 / delivery 35, per-zone); phone-call fallback if app unreachable; device reqs: always charging, wifi, loud speaker.
- Emails: placed(pending), accepted(+time), ready(optional), rejected/missed(+reason); staff notification email list; end-of-day report email.
- Printing: thermal (Epson) auto-print on accept; LAN/Wi-Fi in video, user uses Bluetooth; per printer: template, language, copies; templates Client receipt / Kitchen essentials (no client data, checkboxes, QC); section toggles, font 10-18px, Google Maps QR for address, drive time, signature box, promo info boxes.
- Menu: sizes, addon groups library (min/max, required, preselect), attach to category or item; hide / hide until / show only days+hours; out of stock until tomorrow/date/undetermined (items + addons); labels hot/vegan/vegetarian/halal/raw; allergens; tax category per item; half&half pizza = item price 0 + two required groups (min1 max1) priced per half; combos as items with required groups.
- Hours: per service, exceptions (holidays, open/closed + message), pause; scheduled orders up to 30 days, min/max notice, slot 15min-6h, hide ASAP.
- Delivery: zones circle/polygon, color, min, fee, fee-by-distance, hide; overlap -> lowest min then lowest fee; allow outside-zone toggle; address form fields configurable; customer drops pin; heatmap.
- Dine-in QR per table/room/sunbed (prefix + range), PDF + flyers.
- Multi-location: shared menus, duplicate menu w/ different prices, shared promos.
- Partner/white-label: logo, imprint "Supported by", custom domain, partner dashboard (restaurants, orders, sales, commissions), leads map.
- APIs: Accepted Orders API (push) + Menu API (fetch current menu) -> use for one-click migration import (needs restaurant key from Integrations).
- Pricing: free core; paid: online payments $29/mo, adv promo $19/mo, POS $49/mo/location, reservation deposit $0.5/guest.
- Play Store, "Restaurant Order-Taking App" (GlobalFood, 100K+ installs, rating 2.6): top complaints were no reconnect after a network drop (orders missed until restart), no orders while the app is in the background, the alert forcing the whole phone volume to maximum, order email to one address only, no easy copy of customer details for delivery apps, and low-contrast text. Menuto's Android app addresses each of these.
- Printers (gloriafood.com/how-to-print-restaurant-receipts): Epson and Star thermal printers over LAN, Wi-Fi or Bluetooth; Bluetooth is supported but not recommended by GloriaFood (unstable reconnect, 10 m range). Recommended: Epson TM-T20III/T20II/T82/T82II/T88V, Star TSP143IV/III, TSP654. Bluetooth model listed: Epson TM-m30 (Ethernet + Bluetooth). The owner's printer is an Epson on Bluetooth (exact model still to confirm).
- Fetch Menu API v2: GET https://pos.globalfoodsoft.com/pos/menu, headers Authorization: <key>, Accept: application/json, Glf-Api-Version: 2. Key created in GloriaFood admin → Others → 3rd party integrations → template "Fetch Menu". Size prices are added to the item price; groups can hang on categories, items or single sizes.
